## Established boundaries

- Accepted new-content values may request a draft or future Page date; ordinary construction defaults now, whereas the raw import mapping retains its distinct defaults.
- Unsupported or malformed supplied values retain the handler-specific validation outcome, without giving every API the administration form’s accepted fields.
