# Edit administrative content — moving disabled

## Trigger

An Administrator selects an existing Template admitted by Editable template paths while Template creation restricted is true, then submits revised Source.

## Outcome

Source is stored at the existing Path; the disabled Path input does not rename it. Applicable Twig cache is cleared and rendering invalidated. The creation restriction does not block this ordinary Source edit.
